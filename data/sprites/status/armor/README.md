# Creature armor indicators

Static 16×16 transparent PNG icons, shared by the Java and web clients.

- `light.png`: leather vest
- `medium.png`: chainmail
- `heavy.png`: plate armor

Based on pixel-art concepts created with the built-in image generation tool,
using the game's leather, chain and plate armor sprites as style references.
Prepared at native UI resolution with nearest-neighbor sampling and binary alpha.
No animation, glow or runtime scaling is needed.
